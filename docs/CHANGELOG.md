# 变更日志

本文件按时间顺序追加完整逻辑变更，配合 Git 保存文件级差异。记录时间统一使用北京时间（Asia/Shanghai，UTC+08:00），编号使用递增的 `CHG-NNNN`。

每条记录包含时间、编号、修改内容、原因、影响范围、实际验证结果及未完成事项。提交说明引用对应编号，提交 ID 在交付反馈中提供，不回填当前条目以制造自引用。

已提交记录保持原样；需要纠正时追加新条目并注明被更正的编号。同一事项的编辑、文档同步和验证属于同一条记录，无需为日志自身另建记录。
